# AccuVein, Inc.

> AccuVein builds handheld near-infrared (NIR) vein visualization systems for clinical
> vascular access. The AV500 and AV600 project a real-time image of superficial veins,
> valves and bifurcations onto the surface of the skin so clinicians can assess a site
> before a needle stick. AccuVein is a medical device manufacturer, not a software vendor.

## API surface

AccuVein publishes **no public API**. As of 2026-09-06 there is no developer portal, no
API reference, no SDK, no webhook or event surface, no MCP server, no A2A agent card and
no machine-readable API description (OpenAPI, AsyncAPI, GraphQL SDL, WSDL or Protobuf) on
any host this company controls. `developer.accuvein.com`, `api.accuvein.com` and
`docs.accuvein.com` do not resolve in DNS; `/openapi.json`, `/swagger.json`, `/api-docs`,
`/graphql` and every probed `/.well-known/` path return 404 on `www.accuvein.com`.

The company's own `https://www.accuvein.com/llms.txt` returns HTTP 200 with a zero-byte
body — the file is served but empty, so it carries no guidance for agents. This document
is an API Evangelist-generated profile summary, not a copy of a provider-published file.
